Update: the school wants plus/minus grades. Within each 10-point letter band,
the bottom 3 points get a "-" and the top 3 points get a "+". "A" gets no "+"
(there is nothing above it) but does get "A-", and "F" gets no modifiers at
all. The full table, so there is no confusion:

| score s          | grade |
|------------------|-------|
| 93 <= s <= 100   | A     |
| 90 <= s < 93     | A-    |
| 87 <= s < 90     | B+    |
| 83 <= s < 87     | B     |
| 80 <= s < 83     | B-    |
| 77 <= s < 80     | C+    |
| 73 <= s < 77     | C     |
| 70 <= s < 73     | C-    |
| 67 <= s < 70     | D+    |
| 63 <= s < 67     | D     |
| 60 <= s < 63     | D-    |
| s < 60           | F     |
